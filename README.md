# CAD Engineering Design Portfolio

本 Repository 整理本人於大學期間之 CAD 建模、機構設計與工程繪圖相關成果。

主要使用 SolidWorks 進行零件建模、組合件設計、工程圖製作與機構設計，
並透過實際建模過程培養三維空間概念、尺寸設計、零件配合及工程設計能力。

本作品集亦作為研究所推甄之 CAD 建模與機械設計能力展示。

---

## About This Repository

本 Repository 主要整理以下 CAD 與工程設計內容：

- 3D Part Modeling
- Assembly Design
- Engineering Drawing
- Mechanical Design
- Mechanism Design
- Exploded View
- Dimensional Design
- CAD Visualization
- 3D Printing Design

透過 CAD 建模，將工程構想由概念逐步轉換為可視化的三維模型與工程圖面。
